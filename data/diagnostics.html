Relay valve test

This valve uses constant +12V on BROWN and a switched +12V on BLACK (relay enable). Use STOP anytime to cut power to BLACK.

IN1 LED debug (raw GPIO7)

These buttons bypass the valve logic and directly force GPIO7 HIGH/LOW. If IN1 LED never changes, the relay module input is not actually connected to GPIO7 (or the module input is hard-driven).
